# third_party_local (not shipped in this fork)

Obtain these yourself under their own licences; do not commit proprietary SDKs here.

- NVIDIA DLSS SDK 310.7 → `third_party_local/nvidia/DLSS_SDK_310.7.0` (or set `VEYRA_DLSS_SDK_ROOT`)
- NVIDIA Optical Flow SDK 5.0.7 → `third_party_local/nvidia/Optical_Flow_SDK_5.0.7` (or `VEYRA_NVOF_SDK_ROOT`)
- Intel XeSS SDK 3.0.2 → `third_party_local/intel/xess-3.0.2`
- AMD FidelityFX SDK 2.3.0 → `third_party_local/amd/FidelityFX-SDK-2.3.0`
- nv-codec-headers n13.0.19.0 → `third_party_local/nvidia/nv-codec-headers-13.0`
